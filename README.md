# Docker Freelance Simulation Case #1

## Description
This is a lightweight Python web server containerized with Docker. 
Created as a simulation of a freelance task to demonstrate Docker orchestration and Git workflow.

## How to run
1. **Build the image:**
   ```bash
   docker build -t my-first-app .

2.Run the container:
docker run -p 8080:5000 my-first-app

3.Access the app:
 Open http://localhost:8080 in your browser.
